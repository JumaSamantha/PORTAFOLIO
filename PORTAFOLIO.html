¿Qué es Python?

Python es un lenguaje de programación que sirve para darle instrucciones a la computadora. Se lee casi como texto normal, por eso es muy usado para aprender a programar. Con él se hacen programas, páginas web, análisis de datos e inteligencia artificial.

Listas

Una lista guarda varios elementos en orden. Se puede modificar y acepta valores repetidos y de distintos tipos.

lista = [1, 2, 3]
lista.append(4)
lista.pop()
print(lista)
# [1, 2, 3]

Tuplas

Son como las listas, pero no se pueden cambiar una vez creadas. Sirven para datos que no deben modificarse.

tupla = (4, "Hola", 6.72)
tupla[0] = 8
# TypeError: las tuplas no se pueden modificar

Conjuntos

Guardan solo elementos únicos y no tienen orden. Son útiles para eliminar repetidos.

lista = [1, 2, 3, 2, 1]
print(list(set(lista)))
# [1, 2, 3]

Diccionarios

Guardan pares de clave y valor. Con la clave se llega directo al dato.

alumno = {"nombre": "Silvia", "edad": 21}
alumno["curso"] = "Tercero"
print(alumno["nombre"])
# Silvia

Pilas

El último elemento que entra es el primero que sale, como una pila de libros. Se hacen con una lista.

pila = ["A", "B", "C"]
pila.pop()
print(pila)
# ['A', 'B']

Colas

El primero que llega es el primero en salir, como en una fila para ser atendido.

cola = ["María", "Alejandro", "José"]
cola.pop(0)
print(cola)
# ['Alejandro', 'José']

        res = n1 + n2

        res = n1 - n2
        color = "cyan"
    elif letra == "m":
        res = n1 * n2
        color = "yellow"
    elif letra == "d":
        if n2 == 0:
            messagebox.showerror("Error", "No se puede dividir para 0.")

        res = n1 / n2
        color = "magenta"

        messagebox.showerror("Error", "Opción no válida")
        return

    vida = max(0, vida - 20)

        self.container.pack(pady=10, padx=20, fill=tk.BOTH, expand=True)
        self.crear_pantalla_login()

    def validar(self):
        if self.u.get() == "usuario" and self.p.get() == "1234":
            self.menu()
        else:
            messagebox.showerror("Error", "Datos incorrectos")

    def menu(self):
        self.s = tk.Label(self.container,
                          text=f"Saldo disponible: ${self.saldo}",
                          font=("Arial", 11))
        self.s.pack(pady=5)
        self.m = tk.Entry(self.container)
        self.m.pack(pady=5)
        tk.Button(self.container, text="Depositar", command=self.dep).pack(pady=5)
        tk.Button(self.container, text="Retirar", command=self.ret).pack(pady=5)

    def dep(self):
        v = float(self.m.get())
        self.saldo += v
        self.s.config(text=f"Disponible: ${self.saldo}")

    def ret(self):
        v = float(self.m.get())
        if v <= self.saldo:
            self.saldo -= v
            self.s.config(text=f"Disponible: ${self.saldo}")
        else:
            messagebox.showerror("Error", "Fondos insuficientes")

r = tk.Tk()
CajeroAutomatico(r)
r.mainloop()
